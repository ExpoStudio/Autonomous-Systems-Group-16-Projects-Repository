Welcome to our Project's repository hosted here on GitHub! A repository is an online storage containing all the files and folders related to our project.
It is here for ease of access, ability to measure and see contributions, and ability for all of us edit and make changes to the file from our devices.

To test with the simulator, just copy and then paste the code into the script section of the Pioneer_p3dx object, then run the simulation to test any changes.

If you are unfamiliar with GitHub, There are things called threads. They are used to keep track of multiple versions of a document
I have created 5 additional threads -- one for each member of the team, and one where all 4 of us can collaborate on and edit at the same time. 
DO NOT directly make changes to the main thread. The main thread is our final/updated version of the script. If wanting to make independent changes or experiment, 
please use one of the other threads or create a new one. Request to merge changes onto main thread.
